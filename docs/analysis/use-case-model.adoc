== Hranice a rozsah Systému

=== Uvnitř hranice

*Systém pro správu firemních vozidel a plánování dodávek* a zahrnuje webovou aplikaci, mobilní aplikaci řidiče a vlastní služby nového řešení:

* Získání a využití údajů objednávek přes API (vazby plánu na zdrojové objednávky).
* Automatické sestavení plánu a přidělení jízd řidičům, oprávněné ruční změny plánu majitelem.
* Přiřazení vozidel, rezervace od naložení do vyložení, kontrola časové dostupnosti, prevence konfliktů a posouzení kapacity (včetně blokování překročení).
* Přehled dodávek, využití vozidel a přidělených jízd podle oprávnění.
* Záznam stavů jízdy, potvrzování navržené změny řidičem, nehody a poškození (offline práce a automatická synchronizace).
* Evidence vozidel, jejich přepravních parametrů a termínů STK, uchování historie a souvisejících logů.
* Vlastní uživatelská nastavení a přijetí i předání hlášení podpoře.

=== Vně hranice a mimo rozsah

[cols="2,5",options="header"]
|===
|Oblast |Vymezení
|Interní systém |Výroba, primární evidence objednávek a zákaznických adres, poskytující strana API.
|Zákazník a doručení |Zákazník nemá přístup do B2E řešení. Fyzická přeprava, naložení, vyložení a předání probíhají mimo software; Systém je plánuje nebo zaznamenává jejich události.
|Technická podpora |Vlastní řešení problémů, přihlášení podpory a nový ticket-portál.
|Ostatní vyloučené činnosti |Montáž nábytku, další servis a údržba, personální evidence oprávnění a prohlídek řidičů, směn, dovolených a nemocenských.
|===
