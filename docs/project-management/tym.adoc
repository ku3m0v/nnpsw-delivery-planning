Tento dokument popisuje rozdělení rolí a hlavních odpovědností členů projektového týmu.

== Vedoucí týmu

*Evgenii Kuzmov*

Hlavní odpovědnosti:

* koordinace práce týmu,
* kontrola plnění úkolů,
* komunikace se zákazníkem / cvičícím,
* reprezentace týmu při prezentaci.

== Společná odpovědnost týmu

Role určují hlavní odpovědnosti jednotlivých členů, všechny důležité výstupy projektu však vznikají ve spolupráci celého týmu.

Každý člen týmu musí mít přehled o aktuálním stavu projektu a rozumět návaznosti své práce na ostatní části analýzy.
